# Personal Finance Dashboard

A modern, responsive web application designed to help users manage their personal finances effectively. This project demonstrates best practices in building interactive financial dashboards using vanilla JavaScript, Bootstrap, and custom CSS.

## Overview

The Personal Finance Dashboard provides users with an intuitive interface to track expenses, manage budgets, monitor spending patterns, and gain valuable insights into their financial health. Built with a focus on user experience and responsiveness, this application works seamlessly across all devices.

## Technologies Used

This project leverages modern web technologies to deliver a robust and user-friendly experience:

- **Bootstrap 5.3.x**: Responsive grid system and pre-built UI components
- **Bootstrap Icons 1.11.x**: Scalable vector icons for intuitive navigation
- **Font Awesome 6.5.x**: Comprehensive icon library for enhanced visual communication
- **JavaScript (Vanilla)**: Core functionality and interactive features
- **Custom CSS**: Tailored styling and responsive design enhancements
- **HTML5**: Semantic markup for better accessibility and SEO

---

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side setup required - runs entirely in the browser
- All assets are included locally for offline functionality

### Installation & Usage

1. Clone or download the project to your local machine
2. Open `index.html` directly in your web browser
3. All required CSS and JavaScript files are included in the `assets` folder
4. The application will load with sample data ready for exploration

### Features

- **Dashboard Overview**: Visualize financial summary and key metrics
- **Expense Tracking**: Log and categorize daily expenses
- **Budget Management**: Set budgets and monitor spending against targets
- **Transaction History**: View detailed transaction records
- **Responsive Design**: Seamless experience on desktop, tablet, and mobile devices
- **Offline Capability**: Works without internet connection

## Customization

### Styling
- Modify `assets/css/style.css` to customize the application appearance
- Override Bootstrap variables for consistent theming
- Add custom CSS rules for your specific needs

### Functionality
- Edit `assets/js/script.js` to add new features
- Use `assets/js/function.js` for utility and helper functions
- Leverage Bootstrap JavaScript components for interactive elements

### Configuration
- Update static data in JavaScript files
- Connect to a backend API for persistent data storage
- Implement local storage for client-side data persistence

## Security Considerations

- Implement input validation for user-provided data
- Consider implementing user authentication for multi-user scenarios
